AboutMe

Building software, breaking systems, and writing down the interesting parts — from Kathmandu, Nepal.

I am Aayush Kumar Gupta, a Computer Science and IT student at Lord Buddha Education Foundation (affiliated with Asia Pacific University) based in Kathmandu, Nepal. Driven by a passion for building robust software and understanding modern system architectures, my technical focus spans cross-platform application development, network security, and digital forensics. From engineering desktop applications in C++ and Python—such as the open-source Nepali Date Widget—to exploring vulnerability analysis and system integrity, I bridge code craft with core security fundamentals. Beyond engineering, I share hardware insights and tech tutorials through my YouTube channel, GupLogy, constantly aiming to turn complex technical challenges into clean, open-source solutions.
